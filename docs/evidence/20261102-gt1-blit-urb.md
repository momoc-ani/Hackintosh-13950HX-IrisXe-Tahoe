# GT1 无头模式应用内渲染：Blit3D 固定 URB 表修正

## 问题和结论边界

日期：2026-11-02。主机 13950HX/A788、32 EU、1 slice，Intel headless，RX 6750 XT 负责显示。

前一轮把 `ngreen-l3=8` 改为 `ngreen-l3=4` 后，普通 Metal 顶点 ID、三角形及应用图标恢复。但用户确认应用内部的项目名称、菜单、SVG/按钮和其他图形仍有缺失，完整重开及重建渲染缓存也没有解决。

本轮找到并修复另一个独立的 URB 输入错误：**普通渲染会按硬件能力重新分配 URB，Blit3D 初始化却继续复制一份固定的 896 条目 VS URB 模板。** 仅把该模板的两处条目数改为 512，保留原有起始地址和条目大小后，原本稳定失败的清零、上传、私有缓冲区串联和索引绘制均恢复。

该候选已于 **13:26:01 +0800** 安装，随后用不带 `DYLD_LIBRARY_PATH` 的新进程验收系统安装。真实应用仍需在完整退出重开或重启后，由用户复看原来缺失的界面；不能把独立探针通过写成应用界面已经完全修复。

## 从失败探针到实际驱动

1. 最小索引复现按 `fill -> staging upload -> indexed draw` 执行。原驱动的索引缓冲区读回 `0,0,0`，两个绘制用例失败；AMD 相同操作通过。
2. 单独用 `XE_COPIA_NATIVA=1` 绕过旧对齐拷贝补丁，12 个独立进程的小型索引测试通过。但扩大尺寸和操作顺序后仍失败，所以没有把该绕过开关作为修补安装。
3. `xe-buffer-order` 用独立 compute kernel 读取整个私有缓冲区，避免 blit 读回自身影响判断。矩阵涵盖 8 B 至 4 MiB+68 B、对齐和非对齐偏移、清零后上传、后续部分覆盖以及 private -> private 串联，并逐字节核对数据和未写边界。
4. 仅分开 encoder、逐命令提交等待、额外缓存失效的诊断均未提供完整修复。额外屏障候选只存在于 `build/`，没有安装。
5. REA/Ghidra 反编译安装中的 16.0.32 驱动，确认 `IGAccelBlitCommandEncoder::initializeHWState` 在 `0x969b6`，指令 `0x96b8c` 用 RIP 相对引用复制 `0x43de50` 处 40 字节表。表内两条 `3DSTATE_URB_VS` 都是 `0x10030380`，低 16 位条目数为 896。
6. 前一轮已验证，本机 4-bank 普通渲染的对应命令为 `0x10030200`、512 条目。本轮只改 Blit3D 活跃表里的这两个字段，索引与完整缓冲区矩阵随即通过。重新构建并签名完整候选包后再次通过。

签名前代码与只读数据区实际不同的字节位置只有 `0x43de54`、`0x43de55`、`0x43de5c`、`0x43de5d`。代码签名由 `codesign` 重新生成。未更改另一份未被该初始化函数引用的同名表；`libxedrv.dylib` 与安装前逐字节相同。

这将当前上传失败定位到 Blit3D 固定 URB 模板与本机 GT1 分配不匹配。早期“只绕过对齐拷贝”可以修复少量用例，但不足以覆盖真实渲染数据链。

## 安装和回退

本轮范围为 `/Library/GPUBundles/AppleIntelTGLGraphicsMTLDriver.bundle` 内的用户态 Metal 主程序及其重新生成的签名；EFI、NVRAM boot-args、内核扩展均未更改。继续使用 `ngreen-eu=32 ngreen-l3=4 -ngreenheadless`。

完整回退包：

```text
/Library/GPUBundles/AppleIntelTGLGraphicsMTLDriver.bundle.before-gt1-blit-urb-20261102-132601
```

回退命令：

```sh
sudo zsh tools/rollback-gt1-blit-urb.sh \
  /Library/GPUBundles/AppleIntelTGLGraphicsMTLDriver.bundle.before-gt1-blit-urb-20261102-132601
```

安装以同一文件系统内的目录改名切换完整 bundle，保留正在运行进程的旧文件映射，没有覆盖旧映射中的主程序。新进程已确认从系统目录加载修补后的主程序和原有适配库，签名验证通过。已运行应用和系统服务需要退出重开或重启后才能换用新版本。

构建脚本 `macos/patch-gt1-blit-urb.py` 只面向已确认的 32 EU / 1 slice / L3=4 配置，要求输入为已核对的 16.0.32 / MTL17 布局，先核对初始化引用和完整原始表，再生成全新输出目录。不会自动改写通用构建结果或系统安装。

```sh
python3 macos/patch-gt1-blit-urb.py \
  /Library/GPUBundles/AppleIntelTGLGraphicsMTLDriver.bundle \
  /全新目录/AppleIntelTGLGraphicsMTLDriver-gt1.bundle
# 上述示例要求输入尚未应用本补丁；本轮安装前副本可从完整回退包获得。
sudo zsh tools/install-gt1-blit-urb.sh /全新目录/AppleIntelTGLGraphicsMTLDriver-gt1.bundle
```
